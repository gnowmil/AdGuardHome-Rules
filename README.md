# AdGuardHome-Rules

Custom AdGuardHome filter rules for home network use.

## Rules

| File | Description | Raw URL |
|------|-------------|---------|
| `AntiPCDN.txt` | Block PCDN domains (Bilibili, Tencent Video, iQiyi, Youku, Douyu, Huya, pai ou cloud, and general PCDN providers) | [raw](https://raw.githubusercontent.com/gnowmil/AdGuardHome-Rules/main/AntiPCDN.txt) |

## Usage

In AdGuardHome: Filters -> Custom filtering rules -> Add a new filter with the raw URL above.

## Contributing

Feel free to add more PCDN domains or new rule files.
